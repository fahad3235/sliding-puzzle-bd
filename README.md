# Sliding Puzzle BD

Offline bilingual (English / বাংলা) sliding tile puzzle for Bangladesh — the
classic 15-puzzle family. Slide the numbered tiles into order on a 3×3, 4×4
or 5×5 board. Every shuffled board is **guaranteed solvable**: shuffles are
generated by a random walk from the solved state, never by a random
permutation that could land on an unsolvable board.

Live site: https://fahad3235.github.io/sliding-puzzle-bd/

## Features

- 3 board sizes: 3×3 (Easy), 4×4 (Classic), 5×5 (Hard)
- Tap / click a tile next to the empty space to slide it in
- Keyboard play: arrow keys or WASD
- Move counter and live timer (starts on the first move)
- Best score per board size, saved on-device (fewest moves, then fastest time)
- Win banner with the final move count and time
- Target-order preview strip so new players can see the goal at a glance
- English / বাংলা toggle, persisted, with Bengali digits in বাংলা mode
- Fully offline static site: no network requests, no account, no tracking
- Responsive down to 390 px wide

## How solvability works

A random permutation of a sliding puzzle is solvable only about half the
time (the classic parity rule: for odd-width boards the inversion count must
be even; for even-width boards it depends on the blank's row from the
bottom). Instead of shuffling randomly and hoping, this app shuffles by
making 120–400 random legal moves starting from the solved board. Any board
reachable by legal moves is solvable by definition, so no player ever gets an
impossible puzzle. The parity rule is still implemented (`isSolvable`) and
unit-tested against the textbook cases, including the famous unsolvable
14–15 swap.

## Stack

- Vanilla HTML / CSS / JavaScript — no framework, no build step, no CDN
- `js/logic.js` — pure game logic (board, moves, shuffle, solvability)
- `js/i18n.js` — bilingual strings (Bengali stored as `\uXXXX` escapes so
  sources stay pure ASCII)
- `js/app.js` — UI wiring, timer, best-score persistence
- LocalStorage only, on the player's own device

## Run locally

```sh
# Any static server works, or just open the file:
python3 -m http.server 8000
# then open http://localhost:8000/
```

No install step, no environment variables, no secrets.

See [TEST_RESULTS.md](TEST_RESULTS.md) for the verified results of this run.

## Limitations

- Best scores live in this browser's localStorage; clearing site data erases them.
- No multiplayer, no online leaderboard, no saved mid-game state — a reload
  starts a fresh shuffled board.
- The timer pauses only when the tab is backgrounded by the browser's own
  throttling; it is a casual timer, not a competition clock.
